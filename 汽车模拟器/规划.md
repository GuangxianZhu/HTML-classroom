# 汽车模拟器 · 规划

动手前和你确认过的方案，以及后来的改动记录。

## 目标

最后要做成一个汽车模拟器。第一版只做动力系统：燃油发动机 + CVT，打开前盖能看到它们运转，踩油门看转速、速比、车速、油耗。

## 第 3 步的结果

动力系统的尺寸都在 `params.json`。装进车里以后量出来的间隙（`blender/out/spec.json` 的 `powertrain.fit`）：

| 方向 | 结果 |
|---|---|
| 宽度 | 发动机 + CVT 长 756，纵梁净宽 860，左右各余 52 |
| 高度 | 发动机顶离前盖内板 88，电瓶接线柱离前盖内板 50 |
| 前后 | 离前围板 70，离风扇电机 115 |
| 离地 | 发动机 / CVT 最低点 209，排气管和油箱最低点 184（车身最低点 172） |

第 2 步量过仓库里现成的 2.0L 四缸（`四缸发动机爆炸图`）：加上 CVT 约 931，比纵梁净宽多 71，而且它有 16.9 万个三角形。所以没有用它。

## 第 4、5 步的结果

这套虚构的设定算出来：0→100 km/h 约 11.0 s，极速约 177 km/h，100 km/h 匀速约 6.3 L/100km，N 挡怠速 0.56 L/h，蠕行约 5 km/h，失速转速约 2600 rpm。参数都在 `params.json` 的 `sim` 和 `vehicle` 里，是我按 1.5 L 家用车常见的范围取的。

页面在无头浏览器里打开试过（踩油门、换挡、倒车、四种视图、开前盖、点零件），没有报错。真手机、真显卡、Windows 上的 `启动.bat` 没有试。

## 第 6 步的结果

内饰换成了老车的样子：方向盘后面一个带遮光罩的仪表盒，仪表台中间凸出来一个中控台（两个出风口、收音机、三个空调旋钮），中央通道上一块 P-R-N-D 挡位面板和挡杆，两个吊着的踏板。方向盘、挡杆、两个踏板各是一个物体，原点在转轴上。

仪表的位置是按视线算的：从眼点看过去，表盘的上沿和下沿都要从方向盘气囊盖和轮圈之间那道缝里露出来（现在穿过 54 … 153 mm，缝是 50 … 157）。顺带量了：眼点到顶棚 179 mm，车头前 6.7 m 以内的地面被前盖挡住，踏板踩到底离前围板 32 / 28 mm。都进了自检。

网页加了第五种视图“驾驶位”：拖动画面是转头，看前方 / 看仪表 / 看脚下 三个按钮；表盘上实时画转速表、车速表、挡位和里程；挡杆摆到当前挡、挡位面板上那个字母亮；踏板按踩下的比例绕铰链转；路上有车道线、反光柱、路灯，远处起雾，按真实车速往后跑。在无头浏览器里截图对过，没在真手机上试过。

## 第 7 步的结果

两电机混动的结构是先查实了再建的：发电机和驱动电机同轴、发电机轴从驱动电机的空心轴里穿过去（本田的专利和厂家说明），驱动电机在里、发电机在外（媒体拆解），绕组是扁线（拆解报告）。原来飞度那页把两台电机画成两根平行轴、转子磁钢贴在表面、缸盖是一个实心方块，这三处都改了。

装车：发动机的位置和燃油版一样，水箱、排气、油箱、差速器位置都共用。间隙见 README。电池放在后排靠背后面（早期混动三厢车常见的位置）。

网页：左上角切换动力；混动时仪表前三格换成发动机 / 驱动电机 / 电池，右边多一块电量条，“试试看”换成六个混动的场景；驾驶位的仪表上多一个 EV 灯。能量流在“透视 / 动力总成 / 内部”里画。

这套设定算出来：0→100 km/h 约 8.3 s，100 km/h 匀速约 5.3 L/100km。

没做的：混动的倒车和蠕行；驾驶位的转速表没有换成功率表（只加了 EV 灯）；能量流旁边的数字只在飞度混动原理那页标，这里没标；原理课的第 07 章没有删，只在开头加了一个到这里的入口（它有定速巡航、坡度、禁止直驱这些这里没有的对比）。

## 已知的问题

- 混动：两个页面现在都是 13 ~ 14 MB（多带了一套动力的模型），手机第一次打开比以前慢。
- 混动：电驱单元的壳体还是比较光的回转体和拉伸体，只加了法兰、螺栓和几道筋；PCU、电池的外形是盒子加细节。
- 混动：零件之间有没有穿插只看了渲染图和网页截图，没有自动检查。高压线从前围板下面过转向机那一段是手排的。
- 混动：`启动.bat` 的第 3 项现在会连着建两套动力，没在 Windows 上实跑过。

- 发动机机体、缸盖、CVT 壳体是简化的方块和回转体，只求位置和大小对；里面会动的件做得细一些。
- 急刹到停的时候，速比来不及完全回到最低挡（停下时约 2.35，最低挡 2.48），因为车不动时钢带变不了速比。再起步一动就回去了。
- 变矩器、锁止离合器、CVT 的控制都是最简单的写法：没有换挡手感的标定，没有上坡时主动降挡，倒挡的速比取的是 1。
- 驱动力超过前轮抓地力时只是收油封顶，没有模拟车轮空转。
- 风扇不转，没有水温。
- 零件动作默认放慢 20 倍；选“真实速度”时高转速下零件会看不清，还会有倒转的错觉（画面每秒只有 60 帧）。
- 网页是 9 MB 的单文件，手机第一次打开要等几秒。
- 零件之间有没有穿插没有自动检查，只手算过几处（列在 README 里）。
- 前轮罩内壁在 x = 590，轮胎内侧面在 x = 670，前轮现在最多只能转十几度（估算）。做转向那一步要重做前轮罩和纵梁。
- 地板是按电动车抬高的（下面原来是电池包）。现在排气管和油箱从地板下面走，地板本身没动。
- 方向盘不转（等转向）。中控台的旋钮、收音机、拨杆都是摆设。
- 从眼点看不到踏板（被方向盘下面两根辐条挡着，真车也一样），“看脚下”是把头往左下探着看的。
- 车里的光是均匀的环境光，没有白天黑夜、没有仪表背光照亮车内。
- 这次只重渲了内饰和驾驶员视角两张图；外观那几张渲染图是上一版的（隔着玻璃可能看得到原来的仪表台，很小）。
- `启动.bat` 没在 Windows 上实跑过。
