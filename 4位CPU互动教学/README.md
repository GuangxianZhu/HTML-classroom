# 4 位 CPU 互动教学

给高中水平的初学者一步步看懂一台 CPU：从整体架构到每一根线。单个离线网页，没有外部依赖。

CPU 设计来自开源项目 SimDaSong/4-bit-cpu（MIT 许可）：作者自己设计的 4 位玩具 CPU，9 条指令、8 个寄存器，没有跳转和内存访问。它**不是 SPARC**，第 11 章专门对比两者的差别。

## 怎么打开

- **Windows**：双击 `启动.bat`。先 `git pull --ff-only origin main` 检查更新，再用默认浏览器打开 `index.html`。
- **其他系统 / 手机**：直接打开 `index.html`，或者用仓库首页的在线链接。手机上数据通路图可以左右滑动。

键盘：→ 或空格 = 下一小步。网址后面加 `#7` 直接打开第 7 章。

## 页面里有什么

| 部分 | 说明 |
|---|---|
| 数据通路图 | PC、程序存储器、16 位指令（按字段上色）、译码器和控制信号、8 个寄存器、ALU、写回选择器、ASCII 显示器 |
| 下一小步 | 一条指令拆成 ① 取指 ② 译码 ③ 读寄存器 ④ 运算 ⑤ 写回，橙色线是这一步在用的通路，灰色线“有值但没人用” |
| 说人话 + 电路细节 | 每一小步先用日常比喻说在干嘛（领班、小盒子、岔路口）；勾选“显示电路细节”才显示原电路里的信号名（WE、RSS……）和二进制 |
| 执行前先让我预测 | 勾上以后，每条指令执行前先出一道四选一，猜完再一步步看电路怎么算出来 |
| 12 章讲解 | 每章先出一道选择题让学生预测，答完才显示讲解；讲解里用【源码】【通识】【推断】标出证据强弱 |
| 小工具 | 指令拆解器（输入机器码或汇编看字段和控制信号）、ALU 实验台（逐位看全加器进位）、程序编辑器 |

章节：全景 → 二进制 → 指令格式 → PC 与取指 → 译码器 → 寄存器堆 → ALU 逻辑运算 → 加法器与减法 → 写回与单周期 → DISP 与 ASCII → 自由实验 → 和 SPARC 的差距

## 简化和假设

- **“5 小步”是教学拆分。** 原电路是单周期的：一个时钟周期里所有部件同时工作，周期结束的时钟上升沿才写寄存器。页面里第 ⑤ 步才真正改寄存器，对应这个时钟沿。
- **PC 和程序存储器按 Logisim 版画。** Verilog 版没有 PC，指令由测试文件直接喂进去。
- **DISP 的字符拼法是推断。** 把 Ra 的低 3 位和 Rb 的 4 位拼成 7 位 ASCII 码，依据是 Logisim 里的 TTY 元件和示例程序。Verilog 版里 DWE 没有连到任何东西。
- **ALU 按全加器逐位算**（对应 Logisim 的 fulladder 子电路），Verilog 版写的是 `a + xorB + sub`，两者结果相同。
- 没定义的 opcode 查表得到全 0 控制字，等同 NOP。

## 文件

| 路径 | 内容 |
|---|---|
| `index.html` | 整个页面（打包好的单文件，直接打开） |
| `启动.bat` | Windows 一键启动，含 main 更新检查 |
| `重新打包.bat` | 改了源码后双击：检查更新 → 自检 → 重新打包 `index.html` → 打开（要装 Node.js） |
| `web/src/core.js` | CPU 模型：汇编器、译码器（控制字查表）、全加器 ALU、寄存器堆，`preview()` 算出这一拍每根线上的值，`commit()` 是时钟沿 |
| `web/src/teach.js` | 每一小步的说明（说人话 / 电路细节）和执行前的预测题 |
| `web/src/chapters.js` | 12 章：选择题、讲解、示例程序 |
| `web/src/main.js` | 界面：SVG 数据通路（坐标系 920 × 480）、课程、预测、三个小工具 |
| `web/src/shell.html` | 页面骨架和样式，打包时把脚本塞进去 |
| `web/test_core.mjs` | 自检：示例程序输出 324606、机器码、溢出回绕、反汇编往返、12 章示例程序都能跑完 |

手动打包：

```bash
cd web
npm install
node test_core.mjs   # 自检
node build.mjs       # 生成 ../index.html
```
