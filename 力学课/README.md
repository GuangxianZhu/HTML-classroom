# 力学课：一辆车讲到底

运动学和动力学，从高中讲到大学物理。全程只用一辆车：它从停车场开出来，一路上遇到的每个问题就是一课。

- 每一课回答上一课结尾留下的问题，再留一个新问题给下一课。
- 每一课只引入一个新的量。x、v、a、F、m、E、p 各有固定颜色，整门课不变。
- x-t、v-t、a-t 三张图一课一课叠起来用，后面的课在同一套图上继续画。
- 高中部分讲完以后，大学部分还是这辆车，把前面做过的简化一个个拿掉（加速度不再是常数、有风阻、车轮会转、悬架会晃）。

每一节：先猜一道选择题 → 拖滑块看图怎么变 → 算式下面把当前的数代进去 → 一句话记住。每课最后 5 道练习题，数字每次随机，可以一直刷；做过的课在目录页打勾（存在浏览器本地）。

## 启蒙篇：只会小学数学也能学

目录页最上面是“启蒙 · 先玩明白”，12 小课，写给只有小学数学基础的孩子（比如初一）。学完再看高中第 1～5 课，就是同一批内容的第二遍。

- 顺序倒过来：**先开车，再把开车的过程画成图，最后才起名字。** 每样抽象的东西都让孩子亲手从具体的东西变出来，比如位置-时间图是“每秒拍一张照片，竖起来排开，缩成点，连成线”。
- 一小课只做一件事，五拍：生活里的问题 → 先猜现象 → 用手指拖着车开 → 给看到的东西起名字 → 讲给别人听。步骤一个一个出来，做到了才出“继续”。
- 页面上不出现字母、Δ、斜率、切线、m/s²，式子写成中文词加数字。每课末尾有一栏折起来的“以后课本上会这样写”，链到对应的高中课。
- 练习题数字都能口算，没有负数运算。

## 加一课

1. 在 `course.js` 里把这一课的 `ready` 改成 `true`，写上 `got`（学会的一句话，下一课开头会显示）。
2. 写 `src/lessons/NN.html`（只写正文的几节）和 `NN.js`（图和猜题，开头 `chrome(n)`，结尾 `quiz(n, GEN[n])`）。
3. 在 `problems.js` 里加 `GEN[n]`，5 个生成器，错误选项用常见的错法算出来。
4. 正文里提到别的课写课号，提到的数字加进 `test_mech.mjs`。

## 加一小课（启蒙篇）

1. 在 `course.js` 的 `KIDS` 里把这一小课的 `ready` 改成 `true`，写好 `later`（课末“以后课本上会这样写”）。正式起名字的词写进 `words`，最多 2 个。
2. 写 `src/kids/kNN.html`：一步一个 `<section class="beat">`，要先做到才能往下的那一步加 `data-gate="提示"`；写 `kNN.js`：开头 `kidChrome(n)`、`beats()`，做到了调 `B.unlock('bN')`，结尾 `kidQuiz(n, KGEN[n])`。
3. 在 `kids/problems.js` 里加 `KGEN[n]`，4 个生成器。
4. 跑 `node test_mech.mjs`，字太长、用了没起名字的词都会报出来。
