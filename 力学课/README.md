# 力学课：一辆车讲到底

运动学和动力学，从高中讲到大学物理。全程只用一辆车：它从停车场开出来，一路上遇到的每个问题就是一课。

- 每一课回答上一课结尾留下的问题，再留一个新问题给下一课。
- 每一课只引入一个新的量。x、v、a、F、m、E、p 各有固定颜色，整门课不变。
- x-t、v-t、a-t 三张图一课一课叠起来用，后面的课在同一套图上继续画。
- 高中部分讲完以后，大学部分还是这辆车，把前面做过的简化一个个拿掉（加速度不再是常数、有风阻、车轮会转、悬架会晃）。

每一节：先猜一道选择题 → 拖滑块看图怎么变 → 算式下面把当前的数代进去 → 一句话记住。每课最后 5 道练习题，数字每次随机，可以一直刷；做过的课在目录页打勾（存在浏览器本地）。

## 打开

双击 `启动.bat`（先 `git pull` 检查更新，再打开目录页），或者直接打开 `index.html`。全部离线可用，手机也能看。

## 目录结构

```
力学课/
├── index.html          目录页（打包生成）
├── lessons/NN.html     每一课（打包生成，单文件）
├── 启动.bat
└── web/
    ├── build.mjs       打包：每课的 html 片段套上外壳 + esbuild 打包 js → lessons/NN.html；生成目录页
    ├── test_mech.mjs   自检
    └── src/
        ├── course.js   课程表（唯一的课表来源）
        ├── mech.js     物理和数学（纯函数，课里和题里的数都从这里来）
        ├── problems.js 练习题生成器，每课 5 个
        ├── ui.js       图（Fig）、滑块、算式框、猜题、练习题、画车
        ├── style.css   配色和版式（量的颜色在这里定）
        ├── index.js    目录页的进度
        └── lessons/NN.html + NN.js   每一课的正文和图
```

## 改了以后

```
cd web
npm install        # 第一次
node build.mjs     # 重新生成 index.html 和 lessons/
node test_mech.mjs # 自检
```

自检查三样：课程表前后接得上（做好的课从第 1 课起连续、都写了“学会的一句话”）；正文和猜题里写死的数字（比如 0→100 走了约 154 m、60 km/h 反应 0.8 s 走约 13 m）和 `mech.js` 算出来的一致；每个练习题生成器跑 400 遍，选项是 4 个且不重复、正确选项和算出来的数值对得上、没有 NaN。

## 加一课

1. 在 `course.js` 里把这一课的 `ready` 改成 `true`，写上 `got`（学会的一句话，下一课开头会显示）。
2. 写 `src/lessons/NN.html`（只写正文的几节）和 `NN.js`（图和猜题，开头 `chrome(n)`，结尾 `quiz(n, GEN[n])`）。
3. 在 `problems.js` 里加 `GEN[n]`，5 个生成器，错误选项用常见的错法算出来。
4. 正文里提到别的课写课号，提到的数字加进 `test_mech.mjs`。
