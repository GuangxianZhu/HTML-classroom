1 · 起步

加速度：速度每秒变多少

上一课最后，速度表的指针一直往上走。有人轻轻起步，有人一脚油门到底，差别就在速度变得有多快。

写成数：加速度 = 速度的变化 ÷ 时间，a = Δv ÷ Δt。速度的单位是 m/s，再除以秒，所以加速度的单位是 m/s²，读作“米每二次方秒”，意思是“每秒钟速度涨多少 m/s”。

这台车从 0 加速到 100 km/h 大约要 11 s。平均每秒车速涨多少？

v-t 图上，线越陡加速度越大：加速度就是 v-t 图的斜率。和上一课“速度是 x-t 图的斜率”一模一样，只是往下挪了一层。

2 · 三张图叠在一起

x-t、v-t、a-t 一起看

一趟典型的路：起步加速，匀速开一段，再刹车停下。把位置、速度、加速度三张图上下叠起来，同一个时刻对齐。

每一层都是下一层的“斜率来源”：x 的斜率是 v，v 的斜率是 a。匀速时 v 是平的，a 就是 0；刹车时 v 往下走，a 是负的。

刚起步的那一刻，车速是 0。那一刻的加速度也是 0 吗？

速度是 0 和加速度是 0 是两回事：一个说现在多快，一个说快慢正在怎么变。

3 · 正负号

加速度的方向

加速度也带正负号，它说的是方向，不是快慢。判断车在加速还是减速，看速度和加速度是不是同一个方向：同方向越来越快，反方向越来越慢。
