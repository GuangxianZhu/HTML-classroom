# 电流怎么转动磁场

给物理基础薄弱的人讲电机：不用公式，从指南针开始，一步步讲到三相电、扭矩转速和逆变器。纯 2D 单文件页面，每一步都能动手。

- **网页版（手机可看）**：<https://claude.ai/artifact/1Skg51dhMF8Wjqy2gb5dPs>（默认只有自己能打开，要给别人看需在页面的 Share 里开启分享）
- **离线版**：`index.html`，双击就能看（没网时字体回退到系统字体）

看完可以接着看 [电动车电机调速](../电动车电机调速/)，那边用同一台电机讲 FOC、弱磁和能量回收。

## 怎么打开

- **Windows**：双击 `启动.bat`。它先 `git pull --ff-only origin main` 检查更新（没网或没装 git 就跳过），再用默认浏览器打开 `index.html`。
- **其他系统**：直接打开 `index.html`。

## 九步内容

| 步 | 讲什么 | 动手 |
|---|---|---|
| 1 看见磁场 | 磁场方向就是指南针红头的指向 | 拖指南针，给磁铁调头 |
| 2 电流生磁 | 电流周围有绕圈的磁场，拧瓶盖记方向 | 拖电流滑杆，看指南针偏转和掉头 |
| 3 绕成线圈 | 电流绕圈方向决定哪头是 N，这是全页的核心答案 | 改圈数、反向、加铁芯、切换绕向 |
| 4 一个不够 | 对齐就停，反向遇到死点 | 手动切换电流，试着让转子一直转 |
| 5 比例定方向 | 两组线圈合成，电流比例决定总方向 | 两个滑杆、手动换相（步进电机）、平滑自动 |
| 6 三相电 | 想要某个方向时三组电流该给多少，三相交流由此算出 | 拖手柄，看柱子和波形 |
| 7 扭矩和转速 | 牵狗绳比喻，开环失步，闭环不失步 | 改转速、电流、负载 |
| 8 开关 | H 桥让电流换向，占空比调大小，三种换向路线对比 | 切开关、试短路、拖占空比 |
| 9 真实电机 | Blender 模型截面，名词对照，发电和回收 | 看图 |

每步标了证据强度：公认、本页简化；三处“猜一下”先猜再看。

## 物理都是算出来的

`web/src/physics.js` 是纯函数，`web/test_physics.mjs` 逐项验证方向：

- 电流朝你时磁场逆时针，反向后全部反转
- 线圈内部磁场方向，N 端判断和“逆时针 = N”一致
- 三相合成幅值恒为 1.5 倍、方向等于目标角、三相电流之和为零
- 转子对齐后停止，反向时拉力为零（死点）
- 开环慢升速能同步，跳到高速会失步；闭环转速随负载变化，拉力小于阻力时转不起来
- H 桥四种组合、PWM 平均电流等于占空比

## 和真实情况的差别

- 导线当成无限长，线圈切面用两排长直导线近似，线圈两端只是大致形状
- 线圈磁场和电流成正比，铁芯没有饱和
- 转子是一根两极磁铁，负载是恒定阻力，单位都是相对值
- 第 7 步的转速放慢过，开关波形只画几个周期
- 比喻（瓶盖、拉船、人浪、牵狗绳）只用来帮助理解，页面末尾写了它们哪里不准

## 文件

| 路径 | 内容 |
|---|---|
| `index.html` | 打包好的离线页面 |

## 重新构建

```bash
cd web
npm install
node test_physics.mjs
node build.mjs        # 同时更新上一级的 index.html
```

换截面图：`python blender/render_section.py`（需要 `pip install bpy`，或 `blender -b -P blender/render_section.py`）。
