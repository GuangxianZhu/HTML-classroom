# 立体车库原理演示

6 种立体车库的三维交互演示，单个离线网页（three.js 内联，没有外部依赖）。每一步存 / 取车动作都配一句“为什么这样动”。

| 类型 | 规模 | 看点 |
|---|---|---|
| 简易升降 | 2 层 × 2 列 | 下层有车，上层的车就取不出来 |
| 升降横移 | 3 层 × 3 列 | 每层留一个空位，靠横移让出下降通道 |
| 垂直循环 | 10 个吊篮 | 比较顺 / 逆时针哪边近；所有吊篮一起转 |
| 巷道堆垛 | 2 排 × 4 列 × 3 层 | 行走和升降同时进行，耗时取两者的较大值；空板管理 |
| 垂直升降（塔库） | 8 层 | 单台电梯是瓶颈；载车板式要先取空板 |
| 平面移动 | 3 层 × 2 排 × 4 列 | 升降机和台车分工、预定位；夹轮式不需要载车板 |

## 怎么打开

- **Windows**：双击 `启动.bat`。先 `git pull --ff-only origin main` 检查更新，再用默认浏览器打开 `index.html`。
- **其他系统 / 手机**：直接打开 `index.html`，或者用仓库首页的在线链接。

鼠标左键拖动旋转视角，右键（或中键）拖动平移，滚轮缩放；手机上单指旋转、双指缩放。空格暂停 / 继续，N 键执行下一步。
网址参数：`?type=0`~`5` 直接打开某种车库，`&mode=lab` 直接进原理演示。

## 两种模式

- **司机视角**（默认）：你是来停车的司机，只和右边的出入口终端打交道。点“我要存车”后，车开到入口、识别车牌，确认后系统自动分配车位（画面里用黄框标出），设备先准备好，再提示你把车开进交接区，最后给出存车凭证。取车时选自己的车牌（相当于刷卡），等车送到出口后上车驶离。只有“开进去”“开出来”这两步要你点按钮，其余都是设备自动完成，终端上有进度条和剩余时间。
- **原理演示**：直接点车位按钮存取（有车就取，没车就存）。
  - “自动选位存车”：把每个空位都试算一遍，选模拟耗时最短的。
  - “单步模式” + “下一步”：每个动作都要手动确认，方便讲解。
  - “对比 6 种车库”：每种随机存取 200 次，列出容量、占地和平均耗时。

## 简化和假设

- 设备速度和占地都是示意值，只适合看趋势，不代表真实产品。
- 不建模安全装置（防坠器、光电检测、车长车宽检测）。
- 一次只处理一个请求，不做多个请求排队并发。
- 交接方式：简易升降、升降横移、巷道堆垛、塔库用载车板式；平面移动用夹轮式（没有载车板），这样能和塔库对比“要不要先取空板”。

## 文件

| 路径 | 内容 |
|---|---|
| `index.html` | 整个页面（打包好的单文件，直接打开） |
| `启动.bat` | Windows 一键启动，含 main 更新检查 |
| `重新打包.bat` | 改了源码后双击：检查更新 → 自检 → 重新打包 `index.html` → 打开（要装 Node.js） |
| `web/src/garages/*.js` | 每个文件一种车库：调度逻辑 + 外形描述，不依赖 three.js。想读懂某种车库，直接看对应文件 |
| `web/src/garages/base.js` | 共用基类、动作构造函数（move / turn / loop / spawn / remove）、自动选位 |
| `web/src/motion.js` | 动作原语的纯数学部分（插值、跑道形链条路径） |
| `web/src/scene.js` | three.js 场景：车、车板、标签、高亮框，按动作原语播放动画 |
| `web/src/main.js` | 界面：工具栏、出入口终端、车位按钮、执行步骤、状态图、对比表 |
| `web/src/shell.html` | 页面骨架和样式，打包时把脚本塞进去 |
| `web/test_garages.mjs` | 自检：每种车库随机存取 1500 次，检查不变量，并核对“动画执行到底的位置”和“逻辑算出来的位置”一致 |

调度逻辑和三维绘制是分开的：车库文件只输出“步骤列表”（每一步 = 一句讲解 + 若干个同时开始的动作），`scene.js` 只认识几种动作原语。加一种新车库，只写它自己的调度逻辑和外形。

手动打包：

```bash
cd web
npm install
node test_garages.mjs   # 自检
node build.mjs          # 生成 ../index.html
```
