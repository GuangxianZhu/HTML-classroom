# 热磷酸槽补水控温

湿法槽式机台里刻氮化硅的热磷酸槽（约 160 ℃、85% 左右）是怎么同时把温度和浓度控住的。左边是槽体剖面（石英内槽、外槽溢流、循环泵、在线加热器、过滤器、补水阀、温度计、N2 鼓泡管、排气风门），右边是实时读数，下面是温度 / 浓度 / 执行器三段趋势曲线。纯 2D 离线单文件，没有外部依赖。

## 怎么打开

- **Windows**：双击 `启动.bat`。它先 `git pull` 检查 `main` 有没有更新，再用默认浏览器打开 `index.html`。
- **其他系统**：直接打开 `index.html`。
- 改了 `src/` 以后双击 `重新打包.bat`（需要 Node.js，不用装包）：先跑自检，通过了才重新生成 `index.html`。

## 页面里有什么

- **两条控制路线**，可以随时切换：
  - 沸腾耦合：槽液一直微沸，温度就代表浓度，加热器恒定功率，温度高了开补水阀、低了关。补水规则有区间开关、PI 稳健、PI 激进三种。
  - 温浓分离：加热器把温度控在 160 ±0.3 ℃，浓度计单独控补水，温度出区间时浓度控制暂停，槽液停在沸点下面一点。
- **投片**：50 片常温晶圆吸热、提臂挡住盖子开口；沸腾耦合下可以选投片时补水环怎么处理（照常积分 / 维持基础补水 / 冻结 + 前馈加热）。
- **环境**：大气压（950~1050 hPa，带气压补偿开关）、排气负压（5~20 mmH2O）。
- **读数**：真实浓度、按温度推算的浓度、浓度计读数分开显示，还有沸腾度 0~5。
- **试一下**：8 个一键场景（投片对比、区间开关和 PI、台风天、排气风门、温浓分离投片、温浓分离遇台风、只控温不补水、新液升温）。
- 页底的依据表列出每条机制的出处，页面里的小标签点开能跳过去。

## 文件

| 路径 | 内容 |
| --- | --- |
| `index.html` | 打包好的页面，直接打开 |
| `src/sim.js` | 物理模型和两种控制器（沸点曲线、能量和水平衡、补水死区、温度计和浓度计滞后、投片吸热），浏览器和 Node 通用 |
| `src/page.html` | 页面（剖面图、控件、曲线、场景、依据表），`/*SIM*/` 处由打包脚本塞进 `sim.js` |
| `build.mjs` | 打包：`node build.mjs` |
| `tests/test_sim.js` | 自检：`node tests/test_sim.js`，跑一遍各场景，确认模型表现和页面文案一致 |
| `启动.bat` / `重新打包.bat` | Windows 一键启动 / 自检加打包 |

槽液质量、加热器功率、补水阀流量、排气带走的热量这些都是示意量级，用来让趋势对，不对应某台具体机台。
