# 扭矩、功率、力、速度

零基础动力课：**功率 = 力 × 速度 = 扭矩 × 转速**。从一把扳手讲起，讲到车轮推地面的力、发动机的功率从哪来、电机的扭矩曲线为什么先平后降，最后把油车和电车放在同一张图上比。纯 2D 单文件，不用联网。

五个量从头到尾各用一种颜色：力红、扭矩紫、转速蓝、速度青、功率金。

## 怎么打开

- **Windows**：双击 `启动.bat`。它先 `git pull --ff-only origin main` 检查更新（没网或没装 git 就跳过），再打开 `index.html`。
- 其他系统：直接双击 `index.html`。

## 九步

每一步只多讲一个东西：先猜一道选择题，再拖滑块，下面的算式把当前的数字代进去。

| 步 | 讲什么 | 动手 |
|---|---|---|
| 开头 | 发动机 → 齿轮 → 车轮 → 路面一整串，功率带从头到尾差不多一样宽 | 拖总减速比：推力和车速此消彼长 |
| 1 扳手 | 扭矩 = 力 × 力臂 | 改手上的力和握的位置，够 110 N·m 螺栓才转 |
| 2 车轮 | 车速 = 转速 × 半径，rpm 和 rad/s 怎么换 | 改车轮转速和半径 |
| 3 功率 | 功率 = 力 × 速度 = 扭矩 × 角速度；kW = N·m × rpm ÷ 9549；马力 | 卷扬机吊重物：两种算法得同一个数 |
| 4 齿轮 | 功率不变，拿转速换扭矩 | 改两个齿轮的齿数、输入转速和扭矩 |
| 5 车轮推力 | 推力 = 功率 ÷ 车速；为什么地板油要守在最大功率转速而不是最大扭矩转速；抓地力、风阻、极速 | 推力–车速图，切换守在 6000 / 4200 rpm |
| 6 发动机的功率 | 吸进多少空气就只能烧多少油：14.7 : 1、每 kg 空气约 2.9 MJ、热效率；充气效率让扭矩曲线中间鼓 | 改排量、转速、节气门、增压、热效率，看能量流和扭矩 / 功率曲线 |
| 7 电机的曲线 | 扭矩 = k × 电流；反电动势和基速；弱磁以后恒功率 | 改转速、一键从 0 转到最高、开关弱磁 |
| 8 电机的功率 | 功率 ≈ 电压 × 电流（k 被约掉）；同样 160 kW 做成力优先或速度优先；峰值和持续功率 | 改电压、电流、k（匝数）、齿比，看车轮推力–车速图 |
| 9 油车和电车 | 车轮上最大功率一样时，中高速两条线重合在同一条功率线上，低速各被不同的东西限制；为什么电动车一个齿比就够 | 改车速和电车的齿比，看谁在限制推力 |

最后一张表把五个量的单位和算法列在一起，加三个常见误会。

每步末尾标了证据强度：**公认**（教科书和工程上通用的结论）、**本页简化**（为了讲清楚故意省掉的东西）、**估算**（按常见范围取的数）。

## 数字从哪来

- **例子车**（第 5、9 步）：抄自 [`汽车模拟器/params.json`](../汽车模拟器/params.json)，1325 kg、车轮滚动半径 0.305 m、全开扭矩表（最大 142 N·m @ 4200 rpm，6000 rpm 时 128 N·m 约 80 kW）、CVT 速比 2.484～0.403、主减速 5.895、曲轴到车轮效率 0.87 × 0.97、变矩器模型。那台车是虚构的，这页和那页用的是同一套数。
- **发动机进气模型**（第 6 步）：功率 = 扫气体积 × 充气效率 × 空气密度 1.2 kg/m³ × 增压 × 节气门 ÷ 14.7 × 43 MJ/kg × 热效率。充气效率曲线是估算的；默认 1.5 L、34% 时 6000 rpm 正好算出 80.6 kW、128 N·m，和例子车的扭矩表对得上。
- **电机**（第 7、8 步）：理想电机，不算损失和磁饱和。扭矩 = k × 电流，基速 = 电压 ÷ k，过基速恒功率。默认 400 V、400 A、k = 0.75 N·m/A，即 300 N·m、基速约 5090 rpm、160 kW。
- **第 8 步的电动车**：虚构，1600 kg，后驱，抓地力 = 0.9 × 一半车重。
- **第 9 步的电动版**：和例子车一样重、车轮上最大功率一样（约 68 kW），电机扭矩上限 250 N·m、最高 14000 rpm、齿轮效率 97%。

`web/test_physics.mjs` 有 48 项自检：文案和猜题答案里写死的数字（90 km/h、981 W、294 N·m、4070 N、81 g/s、80 kW、8000 N / 72 km/h……）都用 `physics.js` 重新算一遍，对不上就报错。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 打包好的页面（离线可用） |
| `web/src/physics.js` | 所有的数：纯函数，不碰页面 |
| `web/src/main.js` | 十张图（开头 + 九步，第 6 步两张）、滑块、猜题 |
| `web/src/page.html` | 文字、版式、颜色 |
| `web/test_physics.mjs` | 自检 |
| `web/build.mjs` | 打包：`../index.html`（兄弟项目用相对链接）和 `dist/artifact.html`（链接换成 GitHub Pages 地址，单独发布用） |

## 重新构建

```
cd web
npm install          # 第一次
node test_physics.mjs
node build.mjs
```
