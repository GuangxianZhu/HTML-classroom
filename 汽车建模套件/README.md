# 汽车建模套件（carkit）

用 Blender 脚本（bmesh）按真车的造车顺序建车：**车框 → 车板 → 玻璃 → 座椅 → 内饰**。
一个文件 `carkit.py`，只依赖 Blender 自带的 `bmesh` / `mathutils`（`pip install bpy` 也能跑）。

第一个用它的项目是 `软件定义汽车/`（`blender/build_sdv.py`），可以当完整例子看。

## 怎么用

1. 把 `carkit.py` **复制一份**到项目的 `blender/` 文件夹里（项目文件夹单独拷走也能跑）。
2. 建模脚本里 `import carkit as CK`。
3. 改了副本里的函数，记得回写这里的母版，再同步到其他用到它的项目。

单位毫米，+X 车右、+Y 车头、+Z 朝上；只建右半边，左边镜像。

## 按顺序

| 步 | 函数 | 做什么 |
|---|---|---|
| 0 外皮基准面 | `Skin(section, nseg, y0, y1, smooth_y=40)` | 一圈圈横截面（每个 y 给 nseg+1 个控制点）定义整车外形；`smooth_y` 沿车长把剖面磨顺，车漆反光不折 |
| 1 局部展开图 | `Chart(skin, s_lo, s_hi, s_ref, y_lo, y_hi)` | 按片展开：侧围一张、车顶一张、前盖一张……不把整车摊成一张。缝线、窗洞一律用曲面参数 `(y, s)` 写，相邻两片共用的缝是同一条线 |
| 1½ 侧窗区布置 | `greenhouse(chart, belt, ws_edge, rail, c_line, b_y, div_y)` | 有框车门的侧窗区：前挡侧边平移出 A 柱、车顶分缝往下收出车顶边梁、C 柱线，三段求交倒圆 = 车门上缘；再往里收出窗框饰条、B 柱、后门分隔条和窗洞，前窗前下角切出后视镜底座 |
| 2 车框 | `member()` 贴着外皮扫、`beam()` 不贴外皮 | 帽形截面 + 两边点焊翻边（`shape='hat'`），宽高可以按控制点变；`poke_check()` 检查有没有顶出外皮 |
| 3 车板 | `panel()`、`measure_gaps()`、`arch_cut()`、`wheelhouse()`、`arch_check()` | 区域贴回外皮，边缘退半个缝宽、圆角包边、往里折边；建完在三维里沿每条缝抽点实测缝宽；`arch_check` 查车框有没有伸进轮胎包络（半径 + 8 mm） |
| 4 玻璃 | `glass()`、`glass_bond()` | 玻璃面比钣金低 1 mm，内侧黑釉边；聚氨酯胶条压在开口翻边上（维修手册：胶条 ≥ 14×14 mm） |
| 5 座椅 | `front_seat()`、`bench()` | 按 H 点摆：滑轨、座框、弹簧、调角器、靠背管、头枕杆，外面坐垫和靠背 |
| 6 内饰 | `inner()` | 同一块区域沿法线往里收：门板、顶棚、柱子饰板和车身严丝合缝 |

二维小工具（展开图里画线用）：`offset2` 多边形外扩、`offset_edges2` 每条边各收各的、`line_offset2` 折线平移、`poly_x2` 求交、`clip_half2` 切一刀、`round_corners2` 只倒尖角。

## 规矩（踩过的坑）

- 每做完一步渲一张图看，再做下一步；动手前先查公开专利和维修手册，回复里分清原文数字、专利描述和自己的估计。
- 缝宽以三维实测为准（`measure_gaps` 报 min / p5 / 平均 / p95 / max），不看平面图。
- 贴片必须统一朝外，网格要够密（弦高 ≈ 边长² / 8R，否则会钻到曲面下面）。
- 中线（s = 0 或 nseg）上的边不留缝，左右两半在这里对接。
- 车窗是单层面片：Cycles 渲图别用真折射（光进去出不来、阴影也透不过，车里一片黑），用“透明 + 菲涅尔反射”的薄玻璃；网页里用 alpha 半透明，而且玻璃要单独保持 `transparent`。
- 主灯别放在侧窗、前挡的反射方向上（侧窗往里倾 30° 以上时，左后上方的大灯箱会把整片窗映成白色）。
- 车漆上有明暗斑先做斑马纹检查（车漆换成镜面，环境换成横条纹），条纹断开、打结的地方就是曲面凹进去了；中线剖面（发动机盖、车顶）的坡度要单调变化，横截面拱高别在中间变平。
- 轮胎外侧面要在翼子板里面；轮罩内衬做成黑色，车框、地板、前围、后围都不能伸进轮拱（用 `arch_check`）。
- 后视镜装在前门窗框前下角切出的三角区上（支臂 + 壳体 + 朝后的镜片），不要做成飘在外面的球。
