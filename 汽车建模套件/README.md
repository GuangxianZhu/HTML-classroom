# 汽车建模套件（carkit）

用 Blender 脚本（bmesh）按真车的造车顺序建车：**车框 → 车板 → 玻璃 → 座椅 → 内饰**。
一个文件 `carkit.py`，只依赖 Blender 自带的 `bmesh` / `mathutils`（`pip install bpy` 也能跑）。

第一个用它的项目是 `软件定义汽车/`（`blender/build_sdv.py`），可以当完整例子看；外形怎么从真车参数定出来、查出过哪些问题，见那个项目的 README。
第二个是 `汽车模拟器/`（`blender/build_car.py` + `shape.py`）：直线造型的三厢车，用的是 1.2 版加的“直线 + 圆角”截面。`软件定义汽车/` 里的副本还是 1.1（它用不到新功能，没有动）。

## 怎么用

1. 把 `carkit.py` **复制一份**到项目的 `blender/` 文件夹里（项目文件夹单独拷走也能跑）。
2. 建模脚本里 `import carkit as CK`。
3. 改了副本里的函数，记得回写这里的母版，再同步到其他用到它的项目。

单位毫米，+X 车右、+Y 车头、+Z 朝上；只建右半边，左边镜像。

## 按顺序

| 步 | 函数 | 做什么 |
|---|---|---|
| 0 外皮基准面 | `Skin(section, nseg, y0, y1, smooth_y=40)` | 一圈圈横截面（每个 y 给 nseg+1 个控制点）定义整车外形；`smooth_y` 沿车长把剖面磨顺，车漆反光不折 |
| 0 直板造型 | `Skin(..., interp=fillet_section)`、`skin.crease_lines(nodes)` | 截面改成“直线 + 圆角”：控制点写成 `(x, z, 圆角毫米数)`，控制点之间走直线，板面是平的；圆角给得很大（≥ 半条边）就和前后连成光滑曲线。`crease_lines` 给每道棱出三条线，`panel()` 三角化时当约束边，网格顺着棱走 |
| 1 局部展开图 | `Chart(skin, s_lo, s_hi, s_ref, y_lo, y_hi)` | 按片展开：侧围一张、车顶一张、前盖一张……不把整车摊成一张。缝线、窗洞一律用曲面参数 `(y, s)` 写，相邻两片共用的缝是同一条线 |
| 1½ 侧窗区布置 | `greenhouse(chart, belt, ws_edge, rail, c_line, b_y, div_y)` | 有框车门的侧窗区：前挡侧边平移出 A 柱、车顶分缝往下收出车顶边梁、C 柱线，三段求交倒圆 = 车门上缘；再往里收出窗框饰条、B 柱、后门分隔条和窗洞，前窗前下角切出后视镜底座 |
| 2 车框 | `member()` 贴着外皮扫、`beam()` 不贴外皮 | 帽形截面 + 两边点焊翻边（`shape='hat'`），宽高可以按控制点变；`poke_check()` 检查有没有顶出外皮 |
| 3 车板 | `panel()`、`measure_gaps()`、`arch_cut()`、`wheelhouse()`、`arch_check()` | 区域贴回外皮，边缘退半个缝宽、圆角包边、往里折边；建完在三维里沿每条缝抽点实测缝宽；`arch_check` 查车框有没有伸进轮胎包络（半径 + 8 mm） |
| 4 玻璃 | `glass()`、`glass_bond()` | 玻璃面比钣金低 1 mm，内侧黑釉边；聚氨酯胶条压在开口翻边上（维修手册：胶条 ≥ 14×14 mm） |
| 5 座椅 | `front_seat()`、`bench()` | 按 H 点摆：滑轨、座框、弹簧、调角器、靠背管、头枕杆，外面坐垫和靠背 |
| 5 座椅 | `front_seat(..., mi_insert=)`、`bench(..., mi_insert=)` | `mi_insert` 给坐垫 / 靠背正面中间那一块换一种面料（拼色） |
| 6 内饰 | `inner()` | 同一块区域沿法线往里收：门板、顶棚、柱子饰板和车身严丝合缝 |
| 6 内饰 | `door_ridge()` | 沿车门内侧走的横条：腰线窗台、扶手、储物槽。高度可以给函数（跟着腰线走） |
| 6 内饰 | `xloft()` | 一个 (y, z) 截面沿车宽拉伸：仪表台、后隔板 |
| 7 灯和饰件 | `face_patch()`、`face_y()` | 在正视图 (x, z) 里画轮廓，沿车长投到车头 / 车尾的外皮上：大灯、尾灯、格栅、车牌、车标 |

二维小工具（展开图里画线用）：`offset2` 多边形外扩、`offset_edges2` 每条边各收各的、`line_offset2` 折线平移、`poly_x2` 求交、`clip_half2` 切一刀、`round_corners2` 只倒尖角。

## 规矩（踩过的坑）

- 每做完一步渲一张图看，再做下一步；动手前先查公开专利和维修手册，回复里分清原文数字、专利描述和自己的估计。
- 缝宽以三维实测为准（`measure_gaps` 报 min / p5 / 平均 / p95 / max），不看平面图。
- 贴片必须统一朝外，网格要够密（弦高 ≈ 边长² / 8R，否则会钻到曲面下面）。
- 中线（s = 0 或 nseg）上的边不留缝，左右两半在这里对接。
- 车窗是单层面片：Cycles 渲图别用真折射（光进去出不来、阴影也透不过，车里一片黑），用“透明 + 菲涅尔反射”的薄玻璃；网页里用 alpha 半透明，而且玻璃要单独保持 `transparent`。
- 主灯别放在侧窗、前挡的反射方向上（侧窗往里倾 30° 以上时，左后上方的大灯箱会把整片窗映成白色）。
- 车漆上有明暗斑先做斑马纹检查（车漆换成镜面，环境换成横条纹），条纹断开、打结的地方就是曲面凹进去了；中线剖面（发动机盖、车顶）的坡度要单调变化，横截面拱高别在中间变平。
- 轮胎外侧面要在翼子板里面；轮罩内衬做成黑色，车框、地板、前围、后围都不能伸进轮拱（用 `arch_check`）。
- 后视镜装在前门窗框前下角切出的三角区上（支臂 + 壳体 + 朝后的镜片），不要做成飘在外面的球。
- 外形先在二维里画对再渲：侧视（顶线 / 腰线 / 底线 + 车轮）、俯视（最宽线）、十几个横截面，用 matplotlib 画一张图几秒钟，比渲一张图快几十倍。比例对照真车的公开参数：长宽高、轴距、前后悬。
- 车头车尾不要靠一串手调的点去凑，也不要一刀切平：五条沿车长的曲线先按“车身一直延伸到头”画，最后两三百毫米乘一个超椭圆收口函数（俯视往里收、侧视往最突出的高度收）。解析函数曲率连续，车漆不起斑。
- 前盖 / 尾箱盖的截面用抛物线拱，肩部（翼子板上沿）倒大圆角；乘员舱的肩部才是紧的折线。两种之间按“腰线到顶的高度”过渡。
- 柱子的边不要在 (y, s) 里直接连：参数坐标里的直线到三维里是弯的。给两个端点，在三维里拉直线再贴回外皮（项目里的 `straight_on_skin`）。真车的 A 柱、C 柱侧面看是直线，只在和车顶相接处有一小段圆角；B 柱侧面看是竖直的。
- 几块板交汇的地方（A 柱根、前盖后角、前挡下角）要单独拉近渲一张看：远景看不出来，近看全是从缝里露出来的东西。常见的三种：车里的件比外皮高，从玻璃里戳出来（仪表台两角，要按外皮高度压下去）；浅色的车框、饰板从缝里或玻璃边露出来（用黑色导流板盖住，或把饰板收短）；板缝发白（缝底下垫黑色密封条）。
- 截面配方里两种截面的过渡区要短，而且每个量都要单调平滑。过渡区拖长了，穿过它的柱子会折一下。
- 车轮先对比例再做造型：2025 年的轿车是 18 ~ 20 吋轮辋，胎壁只有 90 ~ 110 mm，轮辋直径约占车轮外径的七成。辐条是扁的铸件，不是圆管；轮辋中间镂空，露出刹车盘。
- 灯、格栅、车牌在正视图里画（`face_patch`），不要在 (y, s) 展开图里画：车头车尾那一段截面挤在一起，形状控制不住；也不要按固定高度去切外皮。
- 黑色底护板只铺到保险杠蒙皮为止。再往前 / 往后底面跟着收口翘起来，从正面能看见，那是车身色的保险杠下沿。
- 两块板在中线上对接的角（尾箱盖下缘正中、保险杠上缘正中）会留一个小缺口，真车也是在这里放车标。
- 渲图：玻璃的反射不要用真镜面（灯箱会在斜玻璃上映成不规则白斑，看着像破洞），按反射方向的仰角给渐变色；灯箱做大（8 米），从后面拍时把灯绕车转 180°。
- 溜背车的后挡下面一定要有后隔板，车顶里面要有顶棚，不然隔着玻璃看到的是车底和车漆背面。
- 内饰的尺寸从 H 点出发定：H 点离地板 240 ~ 300，方向盘中心在 H 点前方约 430、上方约 340，扶手在 H 点上方约 180，仪表台上表面和腰线差不多高。电动车地板高，H 点到地板只能取下限。
- 直板造型（`fillet_section`）的圆角大小全车保持不变。让圆角跟着截面类型一路变大变小，那一片面是扭的，车漆反光起皱（A 柱根最明显）。
- 两种截面（前盖 / 乘员舱）的配方，在交界处要本来就几乎重合，再做过渡。比如让前盖在前挡下沿处的拱高等于车顶边的落差，过渡区就可以很短、不起包。
- 直板车的 A 柱、C 柱就是车顶边那道棱：前后挡玻璃的侧边写成 s = 常数（棱往里约 40 mm），三维里自然是直的，不用再拉直线贴回外皮。车顶边梁包着这道棱，车门上缘在棱下面约 30 mm。
- 车门上缘顺着 A 柱延长，要到前挡下沿前面才碰到腰线（腰线比前挡下沿低）。在 A 柱根竖着切一刀，前门前缝的上端接在这一点，后视镜装在切出来的角上。
- 往里收的内饰板（`inner`）不要跨过紧的棱：收的距离比圆角半径大，面会自己打折。门板收在肩线下面，柱子饰板收在车顶边下面。
- 车框件（`member`）骑在棱上时，截面的两个角会顶出外皮：放到棱的一侧，或者加大 inset。
- 直板车的车头车尾是端面那块平板（`Panel_NoseCap` / `TailCap`），灯和格栅画在它上面。绕过车角的灯只画到圆角的一半，再往外外皮和视线几乎平行，投影会花。
- 保险杠这种“顺着车身轮廓绕一圈”的件：按固定高度取车身的俯视轮廓（`half_width`），沿它扫一根杠。直板车的侧面是立着的，这样取线是稳的。
