行星锥盘无级变速器：拧一下手轮，转速为什么就变了

照片里那种带电机、顶上一个手轮、“200 ~ 1000 转随意调”的小变速器，里面没有一个齿轮在换挡：动力全靠摩擦传，转速靠改变摩擦接触点离中心的距离来调。下面用 Blender 按公开说明和专利建了一台，转起来给你看，再用七个小实验把原理拆开。

叫法

行星锥盘无级变速器、行星摩擦式机械无级变速器；型号常见 MB / MBL / UDL（L 一般指铝壳）。日文资料里归在“摩擦式無段変速機”。

本页这台

0.75 kW 4 极电机，输入约 1400 r/min，手轮调到输出 1000 ~ 200 r/min（速比 1:1.4 ~ 1:7），和照片上写的一样。内部尺寸是我按结构关系定的示意值，不对应任何真实产品。

凸轮环把外夹缝收窄或放宽，盘在槽里整体往里或往外挪，两个接触点离盘心的距离一个变大一个变小，速比就变了。

第一章

两个轮子压在一起，就能传动

没有齿，靠什么传？两个轮子压紧，接触点上两边的表面速度一样（不滑的话），所以转速比就是半径的反比。 能传多大的力，取决于压得多紧：最多是 μ × 压紧力，超过就打滑。

黄点是接触点，红色闪烁表示打滑。动画按 1/60 慢放。

这些变速器里是钢对钢，中间隔着一层油。油怎么还能传力？接触点上压强极高，油膜被压到一瞬间像固体一样，剪切它要花力气，这叫弹流润滑（EHL）下的牵引。 专用的“牵引油”这个系数比普通润滑油高，钢也不直接接触，所以磨损小。 本页取 0.07 / 0.04 是估算值。

还有一个小细节：即使没打滑，从动轮也会比理想值慢一点点（几个百分点以内），这是接触区弹性变形造成的蠕滑。 所以这种变速器带上负载后转速会略微掉一点。

第二章

中间转、外圈不转，行星架就慢慢转

把摩擦轮排成行星机构：中间的太阳轮是输入，外环不转，夹在中间的行星轮被太阳轮搓着自转，又沿着外环滚，所以绕中心公转，带着行星架转。这里用一种“两级行星轮”来讲：行星轮内圈（半径 ρa）碰太阳轮，外圈（半径 ρb）碰外环。

沿主轴方向看。红线是行星轮上的记号，看它自转。慢放 1/60。

怎么算出来的：勾上“站在行星架上看”。这时行星架不动，行星轮只是个过桥轮：太阳轮相对你转得慢了（1400 − n架），外环反过来以 n架 倒转。过桥轮两边表面速度相等：

(1400 − n架) × r × ρb = n架 × R × ρa
⇒ n架 = 1400 / (1 + T)，T = (R/r)·(ρa/ρb)

这就是行星机构的老办法（把行星架当成不动，叫转化机构法，Willis 法）。 本页 r = 40、R = 60 mm。要想调速，就得让 ρa 和 ρb 能变，这就是下一章锥盘的事。

第三章

行星锥盘：接触点在盘面上挪

真机里的行星轮不是两级圆柱，而是一个中间厚、边上薄的双锥盘。主动轮和压盘的刃口从两侧夹住它靠里的一点，定环和凸轮环的刃口夹住它靠外的一点。盘的心轴插在行星架的径向槽里，能整体沿半径挪。（MB 型说明：“带锥度的行星轮内侧夹在主动轮和压盘之间，外侧夹在带锥度的定环和调速凸轮之间”。）

过最上面那个行星盘的轴线剖开、正对着看（和三维的“正对截面”一样）。拖滑块或者拧上面的手轮，两边是联动的。

调速是这样一环扣一环的：

① 凸轮环往里收，外夹缝变窄 → 外侧只能夹在盘更薄、也就是离盘心更远的地方。② 盘被这个楔面推着往里挪（盘心离主轴近了）。③ 于是内侧接触点离盘心近了（ρa 变小）、外侧远了（ρb 变大），T 变小，输出变快。④ 同时内侧夹的地方变厚，把主动轮和压盘撑开，碟簧压得更紧。

反过来松开凸轮环，碟簧通过楔面把盘推回外面，变慢。最快挡盘心离主轴 mm，最慢挡 mm，凸轮环总共只走了 mm 的夹缝变化。

为什么盘一定是“中间厚、边上薄”
  • 主动轮的刃口是一个半径 40 mm 的整圆。它压在盘面上只该碰一个点。盘中间厚时，沿着这个刃口圆往两边走，离盘心越来越远、盘越来越薄，刃口自然离开盘面，只剩一个接触点。
  • 如果反过来做成中间薄、边上厚，沿刃口圆往两边走盘越来越厚，刃口会一路“切进”盘里，装不上。这是本页从几何推出来的，也和“锥盘 = 两个圆锥底对底”的说法一致。
  • 心轴有粗细，接触点不能太靠近盘心：本页最快挡时内侧接触点离心轴表面只剩 mm。专利 CN101398067B 说的正是这个限制：带连体心轴的行星轮，变速范围受轴径限制，工作面只好做得很窄。

第四章

压紧力从哪来，什么时候会打滑

摩擦能传多少，全看压紧力。MB 型的压紧力来自主动轮后面那叠碟簧。 本页模型里有三件事会改变它：

横轴都是输出转速（右边是快挡）。左：每个接触点上的正压力（碟簧总力分到 6 个盘、两个面上）。右：这个挡位最多能传的扭矩和你设的负载。

油：

① 挡位。快挡时盘往里挪、内侧夹的地方厚，碟簧被多压了一截：快挡 N，慢挡 N。

② 离心力。盘随行星架公转，被甩向外，外侧接触点因此比内侧多压一点：快挡多约 %，慢挡几乎为零。

③ 哪一圈先滑。每个盘的自转要平衡：内侧切向力 × ρa = 外侧 × ρb。慢挡时 ρa 大、ρb 小，外侧那圈要出的力是内侧的好几倍，所以慢挡先在外侧滑；快挡反过来先在内侧滑。

把油换成“普通润滑油”试试：同样的压紧力，能传的扭矩按 μ 等比例掉下来。这类变速器要求用指定的油，原因就在这。

另外两条加压路线（各有取舍）
  • 方向一：碟簧恒压（本页、MB 型说明）。结构最简单，不管有没有负载都一直压着。代价是轻载时也压得很紧，摩擦面和轴承一直吃着大力，效率和寿命打折扣。
  • 方向二：按扭矩加压的凸轮。在动力路线上串一个斜面（钢球）凸轮，扭矩越大斜面把盘顶得越紧，轻载就松。US4653349 用的是钢球凸轮，新宝的リングコーン样本也写着内置“自动调压凸轮”。代价是多一套零件，空载时要靠预紧弹簧保底。
  • 方向三：离心力加压。JPH10115356A 让锥形行星轮的支架能摆，公转的离心力把它甩向变速环压紧。好处是转得快压得紧；但低速、起动时离心力很小，要别的办法补。

第五章

快挡被电机卡住，慢挡被摩擦卡住

“这台能带多大的负载”要看两条线谁先到：一条是电机（输入扭矩最多到额定 5.1 N·m，乘上速比和效率），另一条是摩擦（上一章的极限再除以 1.5 倍余量）。

黑点是 UDL010（0.75 kW/4P）样本表上的两个数：最高转速时 6 N·m、最低转速时 12 N·m。 圆圈是你现在的挡位。

快挡（右边）：速比只有 1.4，电机的扭矩放大得少，电机先到额定，能长期用约 N·m，功率 W——基本是把电机功率吃满，这一段接近恒功率。

慢挡（左边）：速比 7，电机扭矩放大 7 倍，本来能给 30 多 N·m，但摩擦只传得了约 N·m，这一段接近恒扭矩。这时电机只用到额定的 %，能输出的功率掉到约 W。

所以这种变速器在低速段功率是浪费的：电机有劲，但摩擦传不过去。这和样本表“最低转速扭矩只是最高转速的 2 倍左右（不是 5 倍）”对得上。 前面那件专利 CN2477894Y 写明要解决的就是低速扭矩。

同样的形状——“低速恒扭矩、高速恒功率”——也出现在 RX 系列行星环锥式的样本里。

第六章

手轮怎么拨动凸轮环，为什么要转着调

本页的调速链：手轮 → 一对锥齿轮 → 蜗杆 → 凸轮环顶上的齿扇。凸轮环被拨转约 °，它背面三段斜坡顶着壳体上的斜坡座，转动变成轴向移动。（MB 型说明里只写到“调速凸轮”，蜗杆、齿扇这些是本页为了让竖着的手轮能拨动它而选的示意结构。）

本页示意 圈走完全程。凸轮升程和手轮转角成正比，但转速不是：拧到一半时是 r/min，不是 600。

为什么不是直线：手轮转角 → 盘心位置是直线关系，但转速 = 1400 / (1 + T)，T 里还有 ρa/ρb 这个除法。本页的尺寸下几个效应互相抵掉不少，所以只是略弯；尺寸不同，弯法也不同。 所以刻度盘最好按实测转速标，不能简单等分。

为什么手一松转速不跑：碟簧的力通过楔面一直在把盘往外推、把凸轮环往外顶。斜坡很缓、蜗杆又有自锁性，这个反推力推不动手轮。 也因此往快挡拧会更费劲一点：那是在压碟簧。

为什么要在运转时调：停着的时候，盘被几千牛的力死死夹住，想让它横着挪，接触点只能硬刮；转着的时候接触点一边滚一边挪，阻力小得多，也不伤面，所以应该在运转中调速。（我没有找到 UDL 原厂说明书原文来确认这一条，是按原理推断的，用之前以你手上那台的说明书为准。）

第七章

要调速，有哪几条路

照片里这种机械无级变速器只是其中一条。按你的场景选，下面三条各有取舍。

机械无级（MB / UDL，本页）变频器 + 定速比减速机行星环锥（Ring-cone / RX 类）
怎么调手轮拧，纯机械改电机的供电频率，可以 PLC / 旋钮 / 通讯远程给定手轮让变速环沿行星锥轴向走
调速范围约 1:5（1.4 ~ 7）宽，低速受电机散热限制 差动输出，能降到很低
转速稳不稳带载后掉几个百分点（蠕滑）开环有转差，加编码器闭环可以很准 同样有蠕滑
低速扭矩被摩擦卡住，功率用不满（第五章）电机扭矩直接经减速机放大，低速长时间运行要注意电机发热 低速恒扭矩
效率比齿轮低（摩擦面的滑动、自旋损失）高 手册给的一种行星锥式只有 0.6 ~ 0.7
要懂电吗不用，插电就转要配线、设参数；会带来电磁干扰，要做滤波和接地 不用
适合现场有人拧、转速偶尔调、不想碰电控的老设备和小产线要自动控制、要联动、要节能的场合。现在新设备多数走这条路（这是我的判断，不是统计）要很低转速或接近零速、又想纯机械的场合

第八章

公开专利里的做法

“行星 + 锥面 + 不转的环 + 改变接触半径”这一族的专利很多。下面这些是本页查到并用来对照的，标了读到哪一步：只看到标题的不作结构推断。本页模型借的是它们的结构关系，尺寸和外形都是自己定的。

结论和边界

哪些是确定的，哪些是本页自己算的

公认 教科书级的原理资料 厂商说明、样本表、专利原文推断 我按原理和几何推出来的估算 本页模型选的数和算出的数

原理

摩擦传动 + 行星机构 + 改变接触半径，速比 n出 = n入 / (1 + (R/r)·(ρa/ρb))。

MB / UDL 的结构

主动轮 + 压盘 + 碟簧夹内侧，定环 + 调速凸轮夹外侧，滑块轴承带行星架输出，输入输出同轴同向，1:1.4 ~ 1:7。

调速链的方向

“凸轮收紧 → 盘往里 → 变快 → 碟簧更紧”是按双锥盘的几何推的；不同厂家可能把碟簧放在外环那一侧，那时方向和受力都会反过来。

扭矩和功率

μ = 0.07、安全系数 1.5、碟簧 1790 N + 60 N/mm、效率 0.9、蠕滑 3% 都是估算。曲线的两头和 UDL010 样本对得上，中间没有数据可对。

没算的

接触应力和疲劳寿命、油温和油的粘度、接触区的自旋损失、轴承摩擦、零件变形。这些决定真机的寿命和发热，本页都没有。

画面上的简化

两个外环、主动轮和压盘都画成对称移动；真机一般是一侧固定、另一侧动，行星盘和主动轮组件跟着轴向浮动一点（CN2477894Y 写的是定环可轴向移动）。
