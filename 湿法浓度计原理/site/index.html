药液有多浓？
半导体湿法设备里的「浓度计」是怎么测出来的

清洗、刻蚀晶圆用的药液（氨水+双氧水、氢氟酸、热磷酸……），浓度差一点，刻掉的厚度就差一截。可药液是透明的、有的还剧毒强腐蚀，人不能拿勺子去尝。设备是靠什么「看出」浓度的？这页把常见的九种测法拆开讲：每种都有可以旋转的 3D 模型、能动手拖滑块的小实验，以及公开专利里是怎么做的。

公认 教科书/物理定律级别的结论 资料 专利、厂商技术资料里写的，可信但是特定条件下 示意 为了讲清楚而简化的图/数，或我的推测

说明：所有模型都是原理示意，不对应任何厂商的具体产品；专利要点是用自己的话概括的，细节请以专利原文为准。

为什么要测浓度？

药液的“劲头”几乎都跟浓度挂钩：刻蚀速率、清洗能力都随浓度变化 公认。而槽里的浓度不会自己保持不变：

  • 分解：双氧水会慢慢分解成水和氧气，温度越高越快 公认
  • 挥发：氨、HCl 会从液面跑掉；高温槽里水也在蒸发 公认
  • 消耗：药液和晶圆表面反应，被用掉一部分 公认
  • 带入 / 带出：晶圆带进来的纯水会把药液冲稀 资料
一句话概括所有浓度计的套路：
找一个随浓度变化、又能用电信号读出来的物理量（吸光、折射率、电导率、声速、密度……）→ 事先用已知浓度的标准液做一条“换算曲线”（标定）→ 实测时查曲线得到浓度。

所以每种方法都要问三个问题：
① 这个物理量还受什么别的影响？（几乎都受温度影响）
② 一个读数会不会对应两个浓度？
③ 药液里有好几个成分时，能不能分开？

浓度计装在设备的哪里？

最常见的做法是：药液一直在 槽 → 泵 → 加热 → 过滤 → 槽 里循环；浓度计装在循环管路上（或从主管分一小股出来的旁路上），把浓度变成电信号送给控制器；浓度低了就补原液，高了就补纯水 资料（见文末“专利里的补液控制”）。

为什么常装在泵和过滤器后面？因为那里流量稳、气泡少——气泡几乎是所有光学和超声浓度计的头号敌人（会散射光、吸收声波）资料。具体装在哪，每台设备不同 示意。

1吸光光度式（近红外 / 紫外多波长）

让一束光穿过药液，看哪些颜色（波长）被“吃掉”了多少。不同分子吃掉的波长不同，所以能一次分出好几个成分。

原理三步

  1. 朗伯–比尔定律：吸光度 A = ε·c·L（ε 是这种分子对这个波长的“吸收能力”，c 浓度，L 光穿过液体的厚度）。浓度翻倍，吸光度翻倍 公认
  2. 分光：透过来的光进分光器，用衍射光栅把波长展开，打到一排检测器上，同时测上百个波长 公认
  3. 多成分联立：几个成分的吸收叠加在一起；用很多已知配比的标准液事先“教会”仪器（化学计量学，如 PCA/PLS），实测时就能把叠加的光谱拆回各成分浓度 资料

近红外区里水本身有很强的吸收带（约 1450、1950 nm，来自 O–H 振动的倍频/合频）公认。所以在稀药液里，“水”本身也是个成分，而且它的光谱会随温度移动——这就是温度补偿的来源 资料。

🔬 动手试试：两个成分 + 温度

曲线形状是示意，不是任何真实药液的光谱。试试：关掉温度补偿，把温度拉到 60 °C。

擅长

一台仪器同时测多个成分（如 SC1 里的 NH₃ 和 H₂O₂）；不接触药液；响应快 资料

依赖的假设 / 何时失效

假设光谱只由“已标定过的成分”造成。混进没标定过的东西（溶解的硅、金属、分解产物）、气泡、窗口被腐蚀或结垢 → 读数偏 资料。石英窗不耐 HF 公认。

常见对象

SC1、SC2、SPM、DHF 等混酸/混碱 资料；紫外区常用于单一吸收强的成分（如臭氧，见 ⑦）

📜 公开专利怎么做的

2折射率式（临界角折射计）

光从棱镜射向药液，斜到一定角度就“弹回来”（全反射）。这个临界角取决于药液的折射率，而折射率随浓度变。

原理三步

  1. 棱镜（常用蓝宝石）的一面直接贴着药液。LED 发出的光以各种角度打到这个面上
  2. 入射角大于临界角 θc 的光全部反射回来，小于的大部分折射进药液：sin θc = n药液 / n棱镜 公认
  3. 反射光打到一排图像传感器上，形成一亮一暗的分界线；分界线的位置 → θc → 折射率 → 浓度 资料

妙处：光只在棱镜表面“擦一下”，几乎不穿过药液，所以颜色、浑浊、气泡对分界线位置影响很小（厂商这样宣称）资料。

🔬 动手试试：拖浓度，看分界线移动

折射率–浓度关系用直线近似 示意；温度系数取 −1×10⁻⁴/°C（水的量级）。

擅长

二元溶液（一种溶质 + 水）；抗颜色/颗粒；无可动部件 资料

依赖的假设 / 何时失效

只输出一个数（折射率），只能解一个未知量。多成分药液、或刻蚀中溶进的硅酸盐等也会改变折射率 → 需要另外补偿 资料。折射率对温度很敏感，必须精确测温 公认。

常见对象

KOH、单一酸/碱稀释液、H₂O₂ 等 资料

📜 公开专利怎么做的

3电磁感应式（无电极）电导率

把药液当成变压器里的一匝导线：药液越导电，传过去的信号越强。线圈全包在氟树脂里，不碰药液。

原理三步

  1. 两个环形线圈套在药液流路上。药液在流路里形成一个闭合的液体环，同时穿过两个线圈 资料
  2. 给第一个线圈通交流电 → 在液体环里感应出电流（像变压器初级→次级）
  3. 液体环的电流又在第二个线圈里感应出电压。药液电导率越高，电流越大，电压越大 → 电导率 → 浓度 公认

没有电极接触药液，所以不怕腐蚀（HF 也行）、不会极化、不会污染药液，适合高浓度强电解质 资料。反过来，导电性极低的超纯水信号太弱，用它不合适——那是 ⑨ 电极式的地盘 公认。

🔬 动手试试：电导率的“驼峰”陷阱

曲线形状参考硫酸（约 30 wt% 处电导率最大，这一点是教科书结论 公认），具体数值为近似 示意。试试把浓度拉到 50 %。

擅长

高浓度、强腐蚀的单一电解质；结构简单、耐用、便宜 资料

依赖的假设 / 何时失效

假设导电的只有目标成分。很多酸碱的电导率在中等浓度有最大值，峰两侧同一读数对应两个浓度 公认。温度每变 1 °C，电导率约变百分之几 → 必须温度补偿 公认。H₂O₂ 这类不电离的成分几乎“看不见” 公认。

常见对象

HF/DHF、HCl、NH₄OH、显影液（TMAH）稀释控制 资料

📜 公开专利怎么做的

4超声波声速式

对着药液“喊一声”（超声脉冲），掐表看多久传到对面。声音在不同浓度的液体里跑得快慢不同。

原理三步

  1. 压电元件被电脉冲激励，发出超声波；对面（或经反射板回来）的压电元件接收 公认
  2. 声速 c = 距离 / 飞行时间。液体里 c = 1/√(ρ·β)（ρ 密度，β 压缩率），两者都随浓度变 公认
  3. 同时测温度，查“声速–温度–浓度”表得到浓度 资料

纯水 25 °C 时声速约 1497 m/s，每升 1 °C 增加约 2.4 m/s 公认——这个温度效应常常比浓度效应还大，所以测温是必须的。

🔬 动手试试：飞行时间

纯水声速用经验多项式计算；“浓度每 1 % 声速 +6 m/s”是示意假设。

擅长

不受颜色/透明度影响；可以和电导率组合，用两个读数解两个成分 资料

依赖的假设 / 何时失效

气泡会强烈散射/衰减超声，是主要误差源 资料。声速–浓度曲线也可能有极值 → 多值问题 推测。

常见对象

酸、碱、混酸的在线监测（常与电导率组合）资料

📜 公开专利怎么做的

5密度式（振动管 / 鼓泡压力）

把药液装进一根会振动的 U 形管：液体越重，管子振得越慢，像吉他弦上挂了重物。

原理三步

  1. U 形管根部固定，用电磁力让它在固有频率振动 公认
  2. 管子体积不变，装进的液体越密，振动部分总质量越大，频率越低：f = (1/2π)·√(k/(m₀+ρV)) 公认
  3. 标定后 ρ = A/f² − B；再用“密度–浓度”表换算 资料

另一种更“土”但耐高温的办法是鼓泡法：从固定深度吹出恒定流量的 N₂，背压 = 液柱重量，跟密度成正比。热磷酸槽有用这种思路的公开专利 资料。科里奥利质量流量计也能同时给出密度 公认。

🔬 动手试试：密度与振动频率

硫酸密度用近似表；“装纯水时 500 Hz”是示意。拉到 95 % 以上看看。

擅长

原理清楚、精度高；任何溶液都有密度，不挑成分 公认

依赖的假设 / 何时失效

同样只给一个数 → 只能解二元溶液。管内气泡、结垢改变振动质量 公认。浓硫酸在约 97–98 % 附近密度有最大值 → 多值 资料。

常见对象

药液调配稀释、热磷酸（鼓泡法）等 资料

📜 公开专利怎么做的

6自动滴定 / 自动化学分析

化学课上的滴定，交给机器人做：取一小份药液，一滴一滴加已知浓度的试剂，直到反应刚好完成。

原理三步

  1. 计量阀精确取一小份样品（常加纯水稀释）放进滴定杯 资料
  2. 活塞泵一点点加入已知浓度的试剂（如 NaOH），同时用电极监测 pH 或电位 公认
  3. 曲线出现突跃处 = 终点。由加入体积和反应计量关系算出原浓度 公认

它测的是真正参与化学反应的量，不需要“物理量↔浓度”的换算曲线，因此常被当作其他在线浓度计的校准基准 推测（在专利里也能看到“快传感器 + 慢滴定校正”的组合 资料）。

🔬 动手试试：强酸被强碱滴定

取样 10 mL，NaOH 0.1 mol/L；pH 由电荷平衡直接计算（强酸强碱，忽略活度）。

擅长

化学上最“直接”；可选择性地测特定成分 公认

依赖的假设 / 何时失效

一次要几分钟到几十分钟，跟不上快速变化 资料；消耗药液和试剂、产生废液；取样管路、试剂老化都会带来误差 公认。

常见对象

定期检查、校准；成分复杂、其他方法分不开时 推测

📜 公开专利怎么做的

7紫外吸收式溶存臭氧计

臭氧对 254 nm 紫外光的吸收特别强，而汞灯恰好主要发这一条光。看紫外光被吃掉多少就知道臭氧有多少。

原理三步

  1. 低压汞灯发出 253.7 nm 强谱线，落在臭氧吸收最强的 Hartley 带里 公认
  2. 光穿过石英测量池里的臭氧水，测量检测器读透过光 I；参比检测器盯着灯本身的 I₀，抵消灯的老化漂移 资料
  3. A = log(I₀/I) = ε·c·L。水中臭氧的摩尔吸光系数约 3000 L·mol⁻¹·cm⁻¹（≈258–260 nm 峰附近）公认

这其实就是 ① 吸光法的“单波长特化版”：成分单一、吸收又强，所以用一个波长就够了。

🔬 动手试试：浓度 × 光程

用 ε = 3000 计算，单位 mg/L ≈ ppm。体会“量程”和“测量池长度”的取舍。

擅长

选择性好、响应快、无试剂 公认

依赖的假设 / 何时失效

假设 254 nm 只被臭氧吸收：水里其他吸紫外的物质会干扰；气泡散射光 → 要先气液分离 资料；汞灯会老化 公认。

常见对象

臭氧水（有机物去除、氧化处理）资料

📜 公开专利怎么做的

8隔膜电极式溶存气体（氢 / 氧）

用一层只让气体通过的薄膜把电极和样水隔开，钻过来的气体在电极上反应产生电流——电流大小 ∝ 气体浓度。

原理三步

  1. 溶在水里的 H₂（或 O₂）分子扩散穿过透气隔膜，进入内部电解液 公认
  2. 在加了恒定电压的铂电极上被氧化（H₂）或还原（O₂），产生电流 公认
  3. 设计成“穿过隔膜”是最慢的一步 → 电流与水中气体分压成正比 资料

这种结构常被称为 Clark 型电极（最早用于溶解氧）公认。用于氢水、脱气纯水的监测。

🔬 动手试试：隔膜脏了会怎样

“透气性约 3 %/°C”是示意量级。

擅长

低浓度溶存气体；结构简单 公认

依赖的假设 / 何时失效

假设隔膜透气性不变：膜脏、破损、内液消耗都会让读数漂移 → 需定期维护校正 公认；温度影响膜的透气性 公认。

常见对象

氢水（功能水）、纯水的溶存氧 资料

📜 公开专利怎么做的

9电极式电导率 / 比电阻（纯水）

严格说它测的是“水有多纯”，而不是药液有多浓：两根电极之间加电压，看能流过多少电流。离子越少，越难导电。

原理三步

  1. 同心的内外电极泡在水里，加交流电压（用交流是为了避免电极极化）公认
  2. 电导 G = I/V；乘上由电极几何决定的“电池常数” K → 电导率 κ；比电阻 = 1/κ 公认
  3. 换算到 25 °C 显示。理论纯水 25 °C 时是 18.2 MΩ·cm，这是水自己电离决定的上限 公认

在湿法设备里常见于纯水供给和冲洗槽：冲洗时药液被逐渐冲掉，比电阻回升到设定值即可判断“冲干净了” 资料。

🔬 动手试试：一点点盐就能“看见”

纯水自电离的温度关系用指数近似，NaCl 按 1 ppb ≈ 0.00216 µS/cm（由摩尔电导率估算）示意。

擅长

极低离子浓度（ppb 级）灵敏 公认

依赖的假设 / 何时失效

浓药液里电极会被腐蚀、极化 → 高电导率要用 ③ 无电极式 公认；温度补偿模型不准时，读数会差很多 公认。

常见对象

超纯水、冲洗终点判断 资料

这一类是非常成熟的通用技术，这里不单列专利。

该选哪种？三种思路

思路 A：光学多组分 较主流

近红外多波长 + 化学计量学，一台测混合液里的多个成分。

取：信息量大、不接触、快。舍：贵；标定工作量大（要做很多标准液、覆盖温度）；对没教过的杂质敏感。

“主流”的判断依据：厂商产品线和多件专利都以它为混合药液的监测手段 资料；各工厂实际占比我无法核实 推测。

思路 B：单一物性 + 温度

电导率、折射率、声速或密度，选一个最灵敏的，配精确测温。必要时两种组合解两成分。

取：便宜、皮实、好维护。舍：只适合二元溶液或已知配比的体系；要留意曲线峰值造成的多值。

思路 C：慢而准的化学分析做基准

在线快速仪表负责实时控制，定期用自动滴定/离线分析去校正它。

取：长期不漂、可追溯。舍：多一套设备与试剂、维护和废液成本。
